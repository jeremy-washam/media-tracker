## Prompt

Research the best current approach for building a complete, tool-capable LLM chat inside a private personal media application.

Assume a standard chat interface. The assistant should answer general questions, search and read the web, and investigate the owner's media library. Recommend other useful capabilities.

Available library data includes books, films, articles, podcasts, music, and videos; creators and metadata; consumption occurrences and dates; ratings, reviews, notes, and highlights; source identities and provenance. Some articles have stored text and searchable passages. Full text and transcripts are not universally available. Dates and source coverage may be incomplete.

Independently recommend the full implementation: model/provider integration, tools and data access, conversation storage, streaming, cancellation, disconnect/reconnect behavior, crash recovery, retries, editing/regeneration, context management, citations, attachments, authentication, privacy, costs, and testing.

Choose the architecture and tools you think fit best. Compare credible alternatives and explain your tradeoffs. Identify assumptions, unresolved questions, and a practical implementation sequence.

Research current official documentation and cite supporting sources. Distinguish documented capabilities from untested assumptions. Research date: 2026-10-29.

Do not read existing project plans, recommendations, memory files, repository implementation, or other agents' reports. No existing stack, API design, runtime, provider, or persistence choices are supplied. Make independent recommendations rather than guessing those choices. Do not implement anything, install dependencies, invoke paid APIs, access credentials, or provision services. Do not spawn other agents. Only use public official web sources for research. Return a complete decision-focused research report with source links adjacent to claims.
