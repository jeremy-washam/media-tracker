# Source logos

These are locally bundled source marks for Connections, retrieved October 13, 2026.
They identify the upstream services; they are not Imladris branding.

- Reader: [official Reader page](https://readwise.io/read), its linked [Readwise mark](https://d34adp677peecb.cloudfront.net/static/images/reader/icons/readwise-logo.2f170ec69bdf.svg).
- Hardcover: [official public assets](https://github.com/hardcoverapp/static-assets), `static/logos/logo-standalone.png`.
- Letterboxd: [official brand assets](https://letterboxd.com/about/brand/), color dots decal for light backgrounds. The asset has an opaque background and retains its original appearance in both themes.
- Spotify: [official design assets](https://developer.spotify.com/documentation/design), `Primary_Logo_Green_RGB.svg` from the icon download.
- YouTube: the official site's 96px favicon from its desktop asset bundle.

Keep the original marks and colors. Import from source so Vite includes them in
normal and deployment builds; do not add live third-party image requests or rely
on the public-directory deployment allowlist. Text headings identify each source,
so these images are decorative for accessibility.
